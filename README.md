# LLM/VLM Dataset Pipeline

## What
A pipeline to generate structured, JSON scene annotations using LLMs and optional VLMs with:
- HyDE (hypothetical doc generation)
- RAG retrieval (TF-IDF retriever)
- Structured output generation
- JSON schema validation
- Basic evaluation & error logging
- Prompt refinement experiment files
